About Knowledge Base

Knowledge Base is a self-hosted, topic-first knowledge platform — a permanent, searchable, linkable home for technical notes, articles, references and experiments accumulated across many sources and tools.

Content is organised by topic rather than by date. Each topic is a landing page that gathers related articles, and every article belongs to a single topic. The result is closer to a personal technical wiki than to a chronological blog.

How it's built

  • Astro 5 with content collections for topics and articles.
  • MDX so articles can embed live, interactive components.
  • React 19 islands, hydrated only when scrolled into view.
  • Tailwind v4 via the Vite plugin for styling.
  • KaTeX (remark-math + rehype-katex) for mathematics.
  • Recharts for charts and data visualizations.
  • Pagefind for static, scalable full-text search.
  • RSS & sitemap for syndication and SEO.

Everything is static and filesystem-driven: no database, no CMS, no server — just content you own, built into plain HTML.
