About Orbital Notes

Orbital Notes is a small personal blog about space and orbital mechanics, written for the curious — not the credentialed. Every post assumes zero prior knowledge of physics or the space domain and builds gently on the one before it.

What makes these posts different is that the explanations are interactive. Instead of staring at a static diagram, you can drag a slider and watch a satellite crash, orbit, or escape in real time. The interactive bits are React components embedded directly inside the writing, hydrated only when you scroll to them.

How it's built

  • Astro 5 with content collections for the posts.
  • MDX so posts can embed live components.
  • React 19 islands, hydrated with client:visible.
  • Tailwind v4 via the Vite plugin for styling.
  • Motion for entrance animations.
  • KaTeX (remark-math + rehype-katex) for the equations.
  • Recharts for the charts.
